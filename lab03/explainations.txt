Lab 03 – PHP + MySQL

1. new mysqli()

Used to connect PHP to MySQL

Example

$conn = new mysqli("localhost", "root", "", "wis_lab");

2. connect_error

Used to check whether the MySQL connection failed

if ($conn->connect_error) {
    die("Connection failed");
}

3. $_POST

Used to receive data submitted from a form using the POST method

$name = $_POST["full_name"];

4. query()

Used to execute an SQL query

$conn->query($sql);

In this lab it is used to create the database and students table

5. close()

Used to close the MySQL connection after finishing the database operations

$conn->close();

6. prepare()

Used to create a prepared SQL statement

It makes inserting user input safer

$stmt = $conn->prepare(
    "INSERT INTO students (full_name, email, department) VALUES (?, ?, ?)"
);

7. bind_param()

Used to connect PHP variables with the placeholders in a prepared statement

$stmt->bind_param("sss", $fullName, $email, $department);

The three "s" values mean that all three values are strings

8. execute()

Used to execute the prepared statement

$stmt->execute();
