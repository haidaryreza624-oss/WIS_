
# Lab Assignment: Laravel 12 Authentication

---

## Lab Parts

| Part | File | Topic |
| ---- | ---- | ----- |
| A | `routes/web.php` | Create named routes for registration, login, dashboard, and logout |
| B | `resources/views/auth/register.blade.php` | Build the registration form with validation feedback and CSRF protection |
| C | `resources/views/auth/login.blade.php` | Build the login form with validation feedback and CSRF protection |
| D | `app/Http/Controllers/AuthController.php` | Implement registration, login, password hashing, and logout |
| E | `resources/views/dashboard.blade.php` | Display the authenticated student's name and email |
| F | `.env` | Configure the MySQL database connection |
| G | `database/migrations/` | Create the database tables using Laravel migrations |
| H | Testing checklist | Test registration, login, dashboard protection, and logout |
